# Pixel Village (Rust)

Мультиплеерная 2D-игра на Rust: клиент на macroquad (Windows / Android), сервер на axum (WebSocket).
Это перенос всей веб-версии игры на Rust.

## Что есть в игре
- **Мир 40×40:** река, озеро, броды, пляжи, три биома (луга, лес, каменистое плато), руды (уголь, медь, железо).
- **Персонаж** с детальной анимацией, поворотом, рюкзаком, инструментом в руке, лодкой и меховой одеждой.
- **Выживание:** сытость, жажда, энергия, здоровье; день и ночь; дождь; смерть с потерей вещей.
- **Добыча по-настоящему:** сначала палки, камешки и нити руками; из них каменные инструменты; дальше медь, железо, печь, плавка.
  Инструменты изнашиваются, топор и кирка трёх уровней, железо берётся только медной киркой и лучше.
- **Крафт:** 22 рецепта (данные лежат отдельно в `client/src/data.rs`, добавлять новые просто). Быстрый крафт под полем (клавиши 1–5) сам предлагает самое нужное: ночью костёр, при голоде еду.
- **Звери:** кролики (копьё), ночные волки (боятся костра), разделка туш ножом, приручение волка (3 раза сырое мясо) и питомец, который дерётся.
- **Рыбалка:** лопата и черви, удочка, поклёвка и вываживание с натяжением лески; рыба с весом, 4 вида.
- **Лодка и мосты.**
- **Мультиплеер (сервер):** видно других игроков с именами, общие ресурсы мира (срубил дерево — исчезло у всех на 8 минут), **рынок игроков** (выставить, купить, снять), рейтинги (очки и лучшие рыбаки), мини-карта.

## Управление
- ПК: WASD или стрелки; Пробел/E добыча; F есть; R пить; G копать; T приручить; B лодка; Y мост; 1–5 быстрый крафт; M или Tab меню.
- Телефон и мышь: вести пальцем по полю; кнопки справа; меню с вкладками «Крафт», «Рынок», «Рейтинг», «Действия».

## Сервер
```
cargo run --release -p server          # порт 8080 (или переменная PORT)
```
- `http://адрес:8080/` — кто онлайн (для всех)
- `http://адрес:8080/admin?key=КЛЮЧ` — для владельца: id, имя, позиция, очки, рекорд рыбы, время в игре, рынок. Ключ в переменной `ADMIN_KEY`; без неё админка выключена.
- `http://адрес:8080/api/players` — JSON
- WebSocket игры: `/ws`
- Хостинг: подойдёт любой, где работают WebSocket; есть `Dockerfile`.

## Клиент
```
cargo run -p client                                   # ws://127.0.0.1:8080/ws
PV_SERVER=wss://ваш-сервер/ws cargo build --release -p client
```
Имя на ПК: переменная `PV_NAME` (иначе «Гравець123»). Для отладки времени суток: `PV_NIGHT=0` (день) или `0.6` (ночь).

Подробная инструкция «как играть с друзьями с телефона»: **ИГРАТЬ_С_ДРУЗЬЯМИ.md**.

## Сборка без компьютера (GitHub Actions)
1. Загрузите проект в репозиторий GitHub.
2. Settings → Secrets and variables → Actions → Variables → `PV_SERVER` (адрес сервера).
3. Actions → Build → Run workflow. Готовые `.exe` и `.apk` появятся в Artifacts.

## Проверки
`cargo test -p client --bins` — 14 тестов механик (добыча, крафт, плавка, рыбалка, лодка, выживание, приручение и др.).
`cargo build -p client --example nettest` и запуск при работающем сервере — проверка мультиплеера (общий мир, рынок, рейтинг).

## Сохранения и имя
- Прогресс сохраняется сам (каждые 8 секунд и при выходе): инвентарь, инструменты, золото, позиция, костры, печи, мосты, дома, питомец. Файл: `%APPDATA%\PixelVillage\save.json` (Windows), `~/.pixel_village/save.json` (Linux/Mac), внутренняя память приложения (Android). Каталог можно задать переменной `PV_SAVE_DIR`.
- Имя вводится при первом запуске экранной клавиатурой (UA/RU/EN), потом меняется в Меню → Действия.
- Подключение по `ws://` и защищённое `wss://` (rustls).

## Пока не сделано
