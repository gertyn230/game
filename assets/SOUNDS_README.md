# 🔊 Звуки та музика для Pixel Village

## 📁 Структура папок:

```
client/assets/
  ├── sounds/          # Звукові ефекти
  └── music/           # Фонова музика
```

## 🎵 Необхідні звукові файли:

### Звуки (client/assets/sounds/):
- `hit.ogg` - Удар (добування дерева, каменю, атака)
- `craft.ogg` - Створення предмета (крафт)
- `eat.ogg` - Їжа
- `drink.ogg` - Пиття води
- `pickup.ogg` - Підбір предмета
- `step.ogg` - Крок (ходіння)
- `death.ogg` - Смерть персонажа

### Музика (client/assets/music/):
- `background.ogg` - Фонова музика (loop)

## 📥 Де знайти безкоштовні звуки:

1. **Freesound.org** - https://freesound.org
   - Найбільша база безкоштовних звуків
   - CC0 ліцензія (можна використовувати без обмежень)

2. **OpenGameArt.org** - https://opengameart.org
   - Спеціалізується на ігрових ресурсах
   - Багато pixel art стилю звуків

3. **Incompetech.com** - https://incompetech.com
   - Безкоштовна музика від Kevin MacLeod
   - Ідеально для фонової музики

## 🎨 Рекомендації:

### Формат:
- **.ogg** (Ogg Vorbis) - найкращий для ігор
- Якість: 128-192 kbps
- Розмір: 10-50 KB для звуків, 1-3 MB для музики

### Стиль:
- Pixel art / 8-bit / chiptune стиль
- М'які, не різкі звуки
- Музика спокійна, атмосферна

## 🔧 Як додати звуки:

1. Завантажте .ogg файли
2. Покладіть у відповідні папки:
   - Звуки → `client/assets/sounds/`
   - Музика → `client/assets/music/`
3. Перейменуйте файли згідно зі списком вище
4. Гра автоматично завантажить їх при запуску!

## ⚙️ Налаштування:

Гравці можуть:
- Вмикати/вимикати музику та звуки окремо
- Регулювати гучність (0-100%)
- Все зберігається в `settings.json`

## 🎮 Що працює зараз БЕЗ файлів:

✅ Система звуків повністю готова
✅ Меню налаштувань працює
✅ Гучність регулюється
✅ Якщо файлів немає - просто тиша (не ламається!)

## 🚀 Після додавання файлів:

Гра автоматично:
- Завантажить всі звуки при старті
- Запустить фонову музику (якщо увімкнена)
- Програватиме звуки при діях (їжа, крафт, удари)
- Застосує налаштування гучності
