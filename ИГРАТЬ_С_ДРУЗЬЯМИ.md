# Как играть с другими (всё делается с телефона)

Схема простая: **сервер** живёт в интернете и соединяет игроков, а у каждого игрока стоит **приложение** (`.apk` на Android или `.exe` на Windows), которое знает адрес сервера.

```
игрок 1 (apk) ──┐
игрок 2 (exe) ──┼──► сервер на Render (wss://…) ◄── ты смотришь, кто онлайн, на сайте
игрок 3 (apk) ──┘
```

Нужно сделать 4 шага. Пойдём по порядку.

---

## Шаг 1. Положить проект на GitHub

1. Зайди на github.com, создай аккаунт (бесплатно) и новый репозиторий: **New repository**, имя например `pixel-village`, **Private** (чтобы код видел только ты), без README.
2. Создай токен для входа с телефона: GitHub → твой аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token**. Отметь галочки **repo** и **workflow**, срок любой, нажми Generate. **Скопируй токен и сохрани** (потом его не покажут).
3. Поставь на телефон **Termux** (с F-Droid, версия из Google Play устарела).
4. Скачай `pixel-village-rs.zip` из чата в «Загрузки» и в Termux выполни по очереди:

```
pkg update -y && pkg install -y git unzip
termux-setup-storage
cd ~
unzip ~/storage/downloads/pixel-village-rs.zip
cd pixel-village-rs
git config --global user.name "ТвойЛогин"
git config --global user.email "твоя@почта"
git init
git add .
git commit -m "первая версия"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/pixel-village.git
git push -u origin main
```

На запрос логина введи свой логин GitHub, а **вместо пароля вставь токен**. Если не получается, пришли мне текст ошибки.

---

## Шаг 2. Запустить сервер (бесплатно, на Render)

1. Зайди на render.com и войди через GitHub. Разреши доступ к репозиторию `pixel-village`.
2. **New → Web Service** → выбери репозиторий.
3. Заполни: **Language: Docker** (Dockerfile уже в проекте), **Instance Type: Free**.
4. **Environment Variables** → добавь `ADMIN_KEY` со своим длинным секретным словом (по нему ты будешь открывать админку).
5. **Create Web Service**. Первая сборка идёт несколько минут. Потом получишь адрес вида `https://pixel-village-abcd.onrender.com`.
6. Открой его в браузере: должна быть страница **«Онлайн: 0»**. Значит сервер работает.

**Как ты видишь игроков:**
- `https://твой-адрес.onrender.com/` показывает, сколько людей и кто онлайн (это видят все).
- `https://твой-адрес.onrender.com/admin?key=ТВОЙ_КЛЮЧ` показывает подробно: имя, позицию, очки, рекорд рыбы, сколько в игре, а также все предложения на рынке. Страница обновляется сама.
- Сами игроки видны и в игре на карте с именами.

**Что важно про бесплатный Render** (условия могут меняться, проверь на render.com/docs/free):
- Если несколько минут никто не играет, сервер «засыпает». Следующему игроку он просыпается около минуты, игра сама пробует подключиться каждые 3 секунды.
- При перезапуске сервера общий мир и рынок обнуляются (рынок и ресурсы хранятся в памяти). Прогресс игроков хранится у них на телефонах.
- Если захочешь, чтобы сервер не засыпал, нужен платный тариф.

---

## Шаг 3. Собрать приложения с адресом сервера

1. В репозитории на GitHub: **Settings → Secrets and variables → Actions → Variables → New repository variable**.
   Имя: `PV_SERVER`, значение: `wss://твой-адрес.onrender.com/ws` (обрати внимание: `wss://` и `/ws` на конце, **без** https).
2. Вкладка **Actions → Build → Run workflow**. Подожди 10–20 минут.
3. Открой завершённый запуск, внизу в **Artifacts** будут:
   - `PixelVillage-android` — файл `.apk`;
   - `PixelVillage-windows` — файл `client.exe`;
   - `server-linux` — тебе не нужен (сервер уже на Render).

Если сборка Android упала, пришли мне текст ошибки из лога: образ сборки мог устареть, это поправимо.

---

## Шаг 4. Играть

- **Android:** скачай `.apk`, открой. Телефон спросит разрешение «установка из неизвестных источников»: разреши для браузера или файлового менеджера. Отправь этот же `.apk` друзьям.
- **Windows:** запусти `client.exe` (Windows может показать предупреждение «неизвестный издатель»: «Подробнее → Выполнить в любом случае»).
- При первом запуске игра спросит имя: набери его экранной клавиатурой (UA, RU, EN).
- Зелёная точка в углу и «Игроков: N (онлайн)» значит, что ты на сервере. Если красная «нет связи», подожди минуту (сервер просыпается) или проверь `PV_SERVER`.

Прогресс сохраняется сам каждые 8 секунд (файл на телефоне или компьютере).

---

## Быстрая проверка у себя (по желанию, нужен компьютер)

```
cargo run --release -p server
cargo run -p client          # в другом окне; второй клиент: PV_NAME=Друг cargo run -p client
```
